# Roadmap — Liveblocks Demo

## v1 — Demo (scope actual)

Construir exactamente esto, sin más:

- [ ] Página principal con editor Tiptap + colaboración en tiempo real
- [ ] Cursores de usuario con nombre y color único
- [ ] Panel de presencia (usuarios conectados)
- [ ] Sistema de comentarios contextuales sobre texto seleccionado
- [ ] Asignación de usuario simulado por sesión (sin auth real)
- [ ] Banners fijos: consultoría, newsletter, repositorio
- [ ] Sección de stack al final de la página
- [ ] Deploy en liveblocks.concriterio.tools

## v2 — Mejoras posibles (si hay tracción)

- Persistencia del documento entre sesiones (Liveblocks Storage)
- Múltiples rooms seleccionables desde la interfaz
- Modo de solo lectura para visitantes sin interacción
- Exportar el documento como Markdown o texto plano
